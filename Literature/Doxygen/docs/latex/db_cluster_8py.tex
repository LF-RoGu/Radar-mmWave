\doxysubsection{Detailed Description}
Implements DBSCAN clustering for radar point cloud data. 

This module applies the DBSCAN clustering algorithm to radar detections, computing cluster properties such as centroids, priorities, range, and azimuth. Clusters are classified based on size, and their properties are returned for further processing.
