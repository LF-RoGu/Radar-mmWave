\doxysubsection{Detailed Description}
Maintains a rolling buffer of radar frames. 

This class stores a configurable number of past frames to enable data persistence and retrieval for multi-\/frame processing. It supports buffer updates, clearing, and retrieving all detected points from stored frames.
