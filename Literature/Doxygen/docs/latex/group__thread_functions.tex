\doxysubsection{Detailed Description}
Functions that run in separate threads to handle sensor data acquisition, processing, and monitoring. 

These functions are executed in parallel using Python\textquotesingle{}s {\ttfamily threading} module. Each function runs indefinitely in its own thread, ensuring real-\/time data handling.

\begin{DoxyParagraph}{Note\+: These functions rely on global variables and require thread-\/safe mechanisms such as locks.}

\end{DoxyParagraph}

{\footnotesize\ttfamily Pipeline\+Live.\+processing\+\_\+thread (\begin{DoxyParamCaption}{ }\end{DoxyParamCaption})}



This function continuously retrieves sensor data frames using the following process\+: 


\begin{DoxyItemize}
\item Decodes incoming frames into usable point clouds.
\item Applies filtering to remove noise and irrelevant data.
\item Estimates self-\/speed using Doppler velocity data.
\item Uses DBSCAN clustering to group detected objects.
\item Stores processed results in global variables for monitoring and processing. The processed data is then stored in shared global variables for monitoring and further analysis.
\end{DoxyItemize}
