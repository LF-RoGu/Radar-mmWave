\doxysubsection{Detailed Description}
Computes and filters effective velocity (Ve) for radar-\/detected objects. 

This module calculates the effective velocity (Ve) of detected objects by using Doppler velocity and the object\textquotesingle{}s azimuth angle. It also filters points based on a threshold relative to the vehicle\textquotesingle{}s self-\/speed.
