\doxysubsection{Detailed Description}
Estimates the vehicle\textquotesingle{}s self-\/speed based on radar Doppler measurements. 

This module processes radar point cloud data to estimate the vehicle\textquotesingle{}s self-\/speed by fitting a polynomial model to the Doppler velocities of detected objects. The method calculates the angle to each target and determines the self-\/speed using polynomial regression.
