\chapter{Pipeline}
\hypertarget{index}{}\label{index}\index{Pipeline@{Pipeline}}
\hypertarget{index_description_main}{}\doxysection{\texorpdfstring{Description}{Description}}\label{index_description_main}
This project aims to develop a real-\/time object detection and collision avoidance system using the IWR6843\+AOPEVM mm\+Wave radar sensor. The system processes raw radar data to extract meaningful information about surroundings, estimate self-\/speed, detect obstacles, and trigger a braking mechanism when necessary.\hypertarget{index_notes_main}{}\doxysection{\texorpdfstring{Notes}{Notes}}\label{index_notes_main}

\begin{DoxyItemize}
\item For this project the bare minimum to be able to replicated is an IWR6843\+AOPEVM mm\+Wave sensor from TI.

\begin{DoxyItemize}
\item Radar Sensor\+: IWR6843\+AOPEVM
\item Processing Unit\+: Raspberry Pi
\item Communication\+: UART interface
\end{DoxyItemize}\hypertarget{index_notes_sec}{}\doxysection{\texorpdfstring{Special Considerations}{Special Considerations}}\label{index_notes_sec}
