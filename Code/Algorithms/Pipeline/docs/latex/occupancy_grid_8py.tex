\doxysubsection{Detailed Description}
Implements occupancy grid processing for radar-\/based mapping. 

This module provides tools for generating Cartesian and Polar occupancy grids from point cloud data, allowing real-\/time environment mapping. The occupancy grid provides spatial representation for detected objects, making it useful for navigation and collision avoidance applications.
