\doxysubsection{Detailed Description}
Implements point cloud filtering based on various spatial and signal properties. 

This module provides functions to filter radar point clouds based on SNR, Cartesian coordinates, Doppler velocity, and spherical coordinates. It allows selective filtering to refine object detection and noise reduction for improved accuracy.
